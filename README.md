# Minecraft 'Azur Sym' modpack
"Spinning sleeves in the returning wind, I raise a toast for you; how long and graceful the singing voice is."  
Azur Sym follows the same lineage as the previous work [Aruori](https://www.mcmod.cn/modpack/626.html). As a small, sweet modpack leaning towards a casual style, it aims to provide a rich game system with the lightest possible weight, rejecting bloatedness and redundancy, with the principle of 'less but refined'.
